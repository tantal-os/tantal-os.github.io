# Contact

We can be reached only through GitHub: [github.com/tantal-os](https://github.com/tantal-os). There is no email or chat.

## Security vulnerabilities

Report privately: open the **Security** tab of the affected repository and choose **Report a vulnerability**. Don't open a public issue for it. The details are in the [security policy](https://github.com/tantal-os/.github/blob/main/SECURITY.md).

## Bugs and suggestions

Open an issue in the repository it concerns. If a bug also reproduces on stock GrapheneOS, say so in the issue and we take it upstream. Don't report Tantal problems to GrapheneOS: the project is not affiliated with us and does not support Tantal.
