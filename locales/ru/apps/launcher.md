# Лаунчер

**Запланировано: сначала макеты, потом код.**

Главный экран — модуль поверх исходников Launcher3 из GrapheneOS. Анимации жестов и экран недавних приложений остаются стандартными.

Макеты лаунчера ещё не нарисованы.

## Возможности

- Свой дизайн главного экрана и дока, списка приложений и поиска, папок, всплывающих меню и выбора виджетов.
- Настройки: сетка, размер иконок и подписей, скрытые приложения, наборы иконок с масками, иконки календаря и отдельные иконки для приложений.
- Жесты: двойное касание блокирует экран, смахивание вниз открывает уведомления или быстрые настройки.
- Поиск находит только приложения.

## Разрешения и сеть

- Без доступа в сеть.
- Без новых привилегированных разрешений.
- Скрытые приложения убраны только из списка, а не защищены. Для защиты есть Private Space.
- Обновляется вместе с системой, а не через магазин.
