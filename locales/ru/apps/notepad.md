# Блокнот

**В разработке** · Исходный код: [tantal-os/notepad](https://github.com/tantal-os/notepad)

Текстовый редактор для файлов любого размера и любого типа. Файлы открываются сразу и читаются по мере прокрутки.

## Возможности

- Файлы любого размера открываются сразу; в памяти только изменённые строки, а при сохранении неизменённые байты копируются как есть.
- Любой файл открывается как текст: нераспознанные байты и концы строк сохраняются, управляющие символы видны как значки Unicode.
- Определение кодировки и концов строк, выбор кодировки.
- Поиск и замена с регулярными выражениями по всему файлу.
- Подсветка синтаксиса для JSON, XML, Markdown, Kotlin, Java, JS, C, Python, shell и файлов настроек.
- Номера строк, перенос слов, отмена и повтор без ограничений, быстрые клавиши над клавиатурой.
- Недавние файлы и черновик, который переживает закрытие приложения системой.

## Разрешения и сеть

- Без разрешений: файлы выбираются через системный диалог.
- Без доступа в сеть.
