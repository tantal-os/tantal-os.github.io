## Features

- Hourly and daily forecast.
- Details: feels like, wind, humidity, UV and more.
- Several locations and city search.
- A weather widget on the home screen.

## Permissions and network

- Location is optional: cities can be added by search.
- Needs the network for forecasts; the forecast source is not chosen yet.
