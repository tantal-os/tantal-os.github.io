# Devlog

## 2026-11-15

- Calendar: month, week, day and schedule views over the system calendar
  provider, so calendars synced by other apps show up too.
- Calendar: search, events with repeats, reminders and a choice of
  calendar; reminder notifications.
- Notepad: files of any size open at once and are edited in place; only
  changed rows stay in memory.
- Any file opens as text; control characters show as Unicode pictures,
  untouched bytes are saved as they were.
- One text field over a moving window of rows: keyboard, cursor and
  selection move between lines freely.
- Find and replace over the whole file in the background.
- Syntax colors for JSON, XML, Markdown, Kotlin, Java, JS, C, Python,
  shell and config files.
- Encodings, line endings, line numbers, word wrap, quick keys, drafts
  that survive the app being killed.

## 2026-11-14

- Calculator: scientific keys (trigonometry, logarithms, roots),
  percentages, degrees and radians, history.
- Clock: alarms with rising volume, snooze and a ring screen; they ring
  before the first unlock after a reboot.
- Clock: world clock, several timers at once, stopwatch with laps.
- Apps moved to one repository each; CI tests every push, a tag publishes
  a signed release.

## 2026-11-07

- Site started: VitePress, Material You theme.
- Web installer mock-up.
